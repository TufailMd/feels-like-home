# 🏠 Feels Like Home (Airbnb Clone)

A full-stack Airbnb clone that allows users to explore properties, book stays, and manage listings with secure authentication and image uploads.

---

## 🌐 Live Demo

👉 https://feels-like-home-one.vercel.app/ 
---

## 🚀 Features

- 🔐 User authentication (Sign up / Login)
- 🏡 Property listings with details
- 📅 Booking system
- 🖼️ Image upload with cloud storage
- 👤 User dashboard
- 🗂️ MVC architecture
- 🌐 Responsive frontend UI

---

## 🛠️ Tech Stack

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- EJS
- Cloudinary (Image storage)
- Multer
- Express Session

### Frontend
- React
- HTML
- CSS
- JavaScript
